# Md. Golam Rasul — Portfolio Website

A responsive static portfolio website built from the CV supplied by Md. Golam Rasul.

## Files
- `index.html` — page content, SEO metadata and structured data
- `styles.css` — responsive design
- `assets/md-golam-rasul.jpeg` — portrait extracted from the supplied CV
- `assets/favicon.svg` — site icon
- `sitemap.xml` and `robots.txt` — search engine discovery helpers

## Publish free with GitHub Pages
1. Create/sign in to a GitHub account at https://github.com.
2. Create a **public** repository named `rasul-portfolio`.
3. Upload the files and folders from this package (upload the contents, not the ZIP itself).
4. Open **Settings → Pages**. Under Build and deployment, choose **Deploy from a branch**, select `main` and `/ (root)`, then Save.
5. Wait for GitHub Pages to publish. The address should look like `https://YOUR-USERNAME.github.io/rasul-portfolio/`.
6. In `index.html` and `sitemap.xml`, replace `YOUR-USERNAME` with your GitHub username. If you use a different repository name, update the URL in both files.
7. In Google Search Console (https://search.google.com/search-console), add the published URL as a URL-prefix property, verify ownership, and submit the sitemap URL. You can also inspect the homepage URL and request indexing.

## Important notes
- Hosting is free on GitHub Pages for a public repository.
- Google indexing is not instant and cannot be guaranteed. A public website, correct links, sitemap, and Search Console help Google discover it.
- Please check all contact details and job history before publishing. The site currently uses the dates and designations shown in the supplied CV.
- The canonical URL in `index.html` is a placeholder until you replace `YOUR-USERNAME`.
- This is a static website; no paid hosting or database is needed.
